# luckydraw-web

행사용 럭키드로우 추첨 프로그램입니다.

## 참가자 등록과 추첨

업로드 화면에서 참가자와 행사 배경 이미지 또는 영상을 등록합니다. 기본값은 `4명 동시`이며, 번호판은 가로로 배치됩니다. Enter 키로 선택한 개수의 사번이 동시에 돌아간 뒤 함께 확정됩니다. 키를 길게 눌러도 추가 추첨을 시작하지 않습니다.

추첨 화면에서 **숫자키 1·2·3·4**를 누르면 번호판 개수만 즉시 바뀝니다. 숫자패드도 Num Lock이 켜져 있으면 사용할 수 있습니다. **F2**로 여는 운영자 설정에서는 이번 추첨의 상품명과 번호판 개수를 변경할 수 있습니다. 예를 들어 네 명을 추첨한 뒤 불참자가 한 명이면 숫자키 `1`을 누르고 Enter로 한 명을 추가 추첨합니다. 개수 변경은 기존 당첨 기록과 남은 참가자를 초기화하지 않습니다. 추첨 중에는 개수를 바꿀 수 없고, 설정 메뉴의 입력란을 편집할 때는 숫자 단축키가 작동하지 않습니다. F2 또는 Esc로 메뉴를 닫을 수 있습니다.

추첨 화면에는 배경 이미지 또는 영상과 숫자 패널을 표시합니다. 영상은 숫자판 뒤에서 소리 없이 자동 반복 재생됩니다. 화면 아래의 당첨자 명단과 저장 버튼은 없습니다. 당첨자 엑셀 저장 기능은 제거했으며 추첨, 화면 이동, 앱 종료 시 엑셀 파일을 만들거나 파일 수정 권한을 요청하지 않습니다.

추첨 횟수에는 제한이 없습니다. 등록된 참가자를 모두 뽑으면 전체 명단을 다시 채워 계속 추첨하며, 한 번의 추첨 안에서는 같은 사번을 중복으로 뽑지 않습니다. 다음 회차를 채울 인원이 부족하면 아직 뽑히지 않은 참가자를 먼저 뽑고 새 순환에서 나머지를 뽑습니다. 같은 사번을 중복 등록해도 한 번만 등록됩니다. 등록된 전체 인원보다 동시에 뽑을 인원이 많을 때만 개수를 줄이도록 안내합니다. F2에는 등록된 참가자 수와 반복 추첨 안내를 표시합니다.

당첨 내역과 남은 참가자는 해당 브라우저 또는 설치형 앱의 로컬 저장소에 함께 보관됩니다. **추첨 화면**을 새로고침해도 명단과 개수 설정이 유지되고, 연출 도중 새로고침한 경우에도 선택된 당첨 결과를 복구합니다. **업로드 화면(`upload.html`)을 다시 열면 이전 당첨 내역과 참가자를 초기화합니다.** 번호판은 다시 4개로 시작합니다. 사이트 데이터 삭제나 다른 PC·브라우저로 이동하면 데이터가 공유되지 않습니다.

백월 이미지와 영상은 브라우저의 IndexedDB(설치형 앱은 앱 내부 IndexedDB)에 보관하며 서버로 전송하지 않습니다. 같은 환경에서 다시 접속하면 유지되지만 다른 기기에서는 다시 등록해야 합니다.

`npm test`로 반복 추첨·중복 방지·데이터 복구를, `npm run self-test`로 실제 Electron 화면, 배경 이미지·영상 업로드와 무음 반복 재생, Enter 추첨, 참가자 업로드와 엑셀 저장 기능 제거를 검증할 수 있습니다.

참가자 엑셀 업로드와 100명 예시 파일 다운로드는 사용할 수 있습니다. 예시에는 `000001`부터 `000100`까지의 테스트 사번이 들어 있습니다. 엑셀의 `사원번호` 또는 `사번` 열을 참가자 번호로 사용할 수 있습니다. 엑셀과 범위 입력 모두 숫자를 최대 6자리까지 받으며, 짧은 번호는 앞에 0을 붙여 등록하고 추첨 화면에 항상 6자리로 표시합니다. 예를 들어 `7`은 `000007`로 표시되고 `012345`는 그대로 표시됩니다.

참가자 등록 화면의 **이미지 / 영상 선택**에서 PNG, JPG, WebP 이미지 또는 MP4(H.264), WebM 영상을 선택할 수 있습니다. 영상도 미리보기와 추첨 화면에서 무음으로 자동 반복 재생되며, **화면 채우기 / 전체 배경 보기** 설정을 따릅니다. 재생할 수 없는 영상은 안내 후 저장하지 않고 기존 배경을 유지합니다. 배경 파일은 앱의 로컬 저장소에 보관되므로 인터넷 연결 없이 유지됩니다. 추첨 화면은 일반 모니터, 4K 디스플레이, 울트라와이드 행사장 화면 크기에 맞춰 번호판을 균일하게 확대·축소합니다. 앱은 항상 전체 화면으로 실행되며 `Esc` 키를 누르면 설정 메뉴가 열려 있는 경우 메뉴를 닫고, 그 외에는 종료됩니다.

설치형 앱에서 예시 엑셀은 운영체제의 `다운로드` 폴더에 내려받습니다.

## macOS 오프라인 앱 만들기

```sh
./build-macos-app.sh
```

빌드가 끝나면 `dist/LuckyDraw.app`을 더블클릭해 실행할 수 있습니다. Windows 버전과 동일한 Chromium 엔진과 동일한 HTML/CSS/JavaScript를 사용하므로 두 운영체제에서 UI가 동일하게 표시됩니다. 엑셀 처리와 축하 효과를 포함한 모든 파일이 앱 안에 들어 있어 실행 시 인터넷 연결이 필요하지 않습니다.

## Windows x64 오프라인 실행 파일 만들기

```sh
./build-windows-exe.sh
```

`dist/windows/LuckyDraw.exe`는 Chromium 런타임과 모든 화면 파일을 포함한 단일 실행 파일입니다. 별도 설치나 인터넷 연결 없이 Windows 10/11 x64에서 실행할 수 있으며 macOS 버전과 같은 UI를 사용합니다.
