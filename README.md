# luckydraw-web

행사용 럭키드로우 추첨 프로그램입니다.

## 상품별 동시 추첨과 번호판 배치

참가자 등록 화면에서 상품명(선택), 당첨 인원, 가로·세로 배치를 미리 설정합니다. 기본값인 `4명 동시`로 추첨하면 같은 상품의 당첨 사번 4개가 동시에 돌아간 뒤 함께 확정됩니다. Enter 키로 시작하며, 키를 길게 눌러도 추가 추첨을 시작하지 않습니다.

추첨 화면에서 **F2**를 누르면 운영자 설정 메뉴가 열립니다. 번호판을 **1·2·3·4개**로 바꾸거나 가로·세로 배치, 이번 추첨의 상품명, 당첨 기록 위치를 변경한 뒤 `적용`을 누릅니다. 예를 들어 네 명을 추첨한 뒤 불참자가 한 명이면 1개로 바꿔 추가 추첨할 수 있습니다. 설정 변경은 기존 당첨 기록이나 남은 참가자를 초기화하지 않습니다. 추첨 중에는 설정을 변경할 수 없고, 메뉴가 열린 동안에는 추첨을 시작하지 않습니다. F2 또는 Esc로 메뉴를 닫을 수 있습니다.

당첨이 확정되면 번호가 회차·상품명과 함께 화면 옆이나 아래의 기록 영역에 자동으로 쌓입니다. 최신 회차가 먼저 보이며 이전 기록은 스크롤로 확인할 수 있습니다. 기본값인 자동 배치는 넓은 화면이나 세로 번호판에서는 오른쪽, 그 외에는 아래를 사용합니다. 오른쪽 배치를 선택해도 화면이 좁으면 아래로 배치해 번호판과 겹치지 않게 합니다. 추첨 연출 중에는 새 당첨 번호를 기록 영역에 미리 공개하지 않습니다.

`가로 배치`는 사번을 나란히, `세로 배치`는 위에서 아래로 표시합니다. 당첨자는 이후 추첨에서 자동 제외하며, 같은 사번을 중복 등록해도 한 번만 참여합니다. 현장에 없는 당첨 번호도 계속 제외됩니다. 남은 참가자가 설정 인원보다 적으면 추첨을 시작하지 않고 F2에서 개수를 줄이도록 안내합니다.

중복 당첨 방지와 결과 복구를 위해 당첨 내역과 남은 참가자는 해당 브라우저 또는 설치형 앱의 로컬 저장소에 함께 저장됩니다. 새로고침해도 화면의 기록이 복구되고, 연출 도중 새로고침한 경우에도 선택된 당첨 결과를 복구합니다. 선택한 번호판 개수, 가로·세로 배치, 상품명, 기록 위치도 유지됩니다. **참가자를 새로 등록하면 새 행사로 시작하며 이전 당첨 내역을 초기화합니다.** 사이트 데이터 삭제나 다른 PC·브라우저로 이동하면 데이터가 공유되지 않습니다.

백월 이미지는 브라우저의 IndexedDB(설치형 앱은 앱 내부 IndexedDB)에 보관하며 서버로 전송하지 않습니다. 같은 환경에서 다시 접속하면 유지되지만 다른 기기에서는 다시 등록해야 합니다.

`npm test`로 추첨·중복 방지·저장 복구를, `npm run self-test`로 실제 Electron 화면과 연출을 검증할 수 있습니다.

엑셀의 `사원번호` 또는 `사번` 열을 참가자 번호로 사용할 수 있습니다. 엑셀과 범위 입력 모두 숫자를 최대 6자리까지 받으며, 짧은 번호는 앞에 0을 붙여 등록하고 추첨 화면에 항상 6자리로 표시합니다. 예를 들어 `7`은 `000007`로 표시되고 `012345`는 그대로 표시됩니다.

참가자 등록 화면에서 PNG, JPG, WebP 행사 배경 이미지를 선택할 수 있습니다. 이미지는 브라우저나 외부 서버가 아니라 앱의 로컬 저장소에 보관되므로 인터넷 연결 없이 유지됩니다. 추첨 화면은 일반 모니터, 4K 디스플레이, 울트라와이드 행사장 화면 크기에 맞춰 번호판을 균일하게 확대·축소합니다. 앱은 항상 전체 화면으로 실행되며 `Esc` 키를 누르면 설정 메뉴가 열려 있는 경우 메뉴를 닫고, 그 외에는 종료됩니다.

예시 엑셀 파일은 운영체제의 `다운로드` 폴더에 저장됩니다. 같은 이름의 파일이 이미 있으면 기존 파일을 덮어쓰지 않고 `(2)`, `(3)`처럼 번호를 붙여 저장한 뒤 파일 위치를 표시합니다.

## macOS 오프라인 앱 만들기

```sh
./build-macos-app.sh
```

빌드가 끝나면 `dist/LuckyDraw.app`을 더블클릭해 실행할 수 있습니다. Windows 버전과 동일한 Chromium 엔진과 동일한 HTML/CSS/JavaScript를 사용하므로 두 운영체제에서 UI가 동일하게 표시됩니다. 엑셀 처리와 축하 효과를 포함한 모든 파일이 앱 안에 들어 있어 실행 시 인터넷 연결이 필요하지 않습니다.

## Windows x64 오프라인 실행 파일 만들기

```sh
./build-windows-exe.sh
```

`dist/windows/LuckyDraw.exe`는 Chromium 런타임과 모든 화면 파일을 포함한 단일 실행 파일입니다. 별도 설치나 인터넷 연결 없이 Windows 10/11 x64에서 실행할 수 있으며 macOS 버전과 같은 UI를 사용합니다.
