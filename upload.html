🎉 경품 추천 참가자 업로드 페이지

📌 엑셀 파일 준비 규칙

✔ 데이터는 반드시 A1부터 시작해야 합니다.
  ㆍA1 = 컬럼명(헤더)
  ㆍA2부터 실제 데이터 입력

✔ A열에 ‘번호 컬럼’이 반드시 있어야 함
가능 컬럼명: no, 번호, number, 연번, participantNo

✔ B열 이름 컬럼은 선택사항
가능 컬럼명: 이름, 성함, name

✔ 참가자 번호는 숫자 형태여야 함
허용 범위: 00000 ~ 99999
예: 7 → 00007 / 123 → 00123

✔ 추가 컬럼 있어도 OK
✔ 첫 번째 시트만 사용
✔ 빈 행/문자열 번호는 자동 제외
