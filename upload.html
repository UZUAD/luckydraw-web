행사 추첨 운영을 위한 참가자 업로드 페이지

본 페이지는 럭키드로우 프로그램에서 사용할 참가자 번호를 엑셀 파일 또는 번호 범위로 등록하고, 제외 대상 반영 후 추첨 화면으로 전달하기 위한 사전 준비 페이지입니다.

등록 규칙

1. 데이터 시작 위치

A1에는 헤더가 있고, 실제 데이터는 A2부터 시작해야 합니다.

2. 번호 컬럼 이름

no 번호 number 연번 participantNo 중 하나가 필요합니다.

3. 참가자 번호 형식

번호는 숫자여야 하며 자동으로 5자리로 맞춰집니다.
예: 7 → 00007, 123 → 00123

4. 이름 컬럼은 선택사항

이름 컬럼은 없어도 됩니다. 추가 컬럼도 허용됩니다.

5. 첫 번째 시트 및 추가 컬럼

A열 번호 기준으로 추첨하며, 번호 컬럼이 정상적으로 구성되어 있으면 추가 컬럼은 함께 포함되어도 무방합니다. 빈 값이나 숫자가 아닌 데이터는 업로드 과정에서 자동 제외됩니다.

6. 번호 범위 직접 입력

엑셀 없이 시작 번호와 끝 번호를 입력하면 해당 범위의 번호가 모두 생성되며, 추첨 제외 번호도 동일하게 반영됩니다.

참가자 번호 등록

엑셀 파일을 업로드하거나 시작 번호와 끝 번호를 직접 입력하세요.
